# Ahmed Abdel Fattah — Data Analyst Portfolio

Modern, high-performance Data Analyst portfolio website built with React, Vite, Tailwind CSS, and Lucide Icons.

## 🚀 Tech Stack
- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS + Custom Cyberpunk Animations
- **Icons:** Lucide React
- **Email:** EmailJS integration
- **Theme:** Dark Terminal / Business Intelligence Analytics

## 🛠️ Local Development
```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```

## 🌐 Live Website
Deployed on [Vercel](https://vercel.com).
